# Phase 1 workflows

Sign in using a labeled demo persona. Home and Client Groups show only authorized relationships. Search groups, individuals, entities and advisors within that scope. Create a Client Group with exactly one active Partner, Relationship Manager and service team. Create people, households and entities from a group; associate existing legal masters without duplicating them. Add reusable advisors with private group scope notes. Add household memberships with effective dates.

Use Family & Households and Entities & Ownership to inspect diagrams. Change the as-of date to evaluate actual effective intervals. Filter edge types, zoom/pan, collapse branches and select records to inspect profiles. Record a new ownership percentage with an effective date to split an existing interval; prior graphs remain reproducible. Maintain assignment history when the primary team/Partner/RM changes. Archive groups and parties instead of deleting. Administration manages reference types, current team membership and scoped audit history.

Financial, contract, service-line, activity, tasks and integration workflows are deferred; navigation does not imply those features exist.

Users can update group name/status/SharePoint root, edit shared masters when authorized across every associated group, edit advisor group context, and end relationship, advisor or household-membership intervals with an audited reason. Dependent relationships must end before an advisor association can end. Default business-date selection is America/New_York.
