# Interface

Desktop-first light workspace with a dark green navigation rail, restrained typography, muted sage accents, bounded tables, consistent badges, clear errors and empty states. Phase 1 navigation: Home, Client Groups, Individuals, Entities & Trusts, Advisors, Administration. Global search returns only authorized records. Directory filters include status, Partner, RM and team; saved views are local to the signed-in employee. Lists use bounded server responses and pagination.

Client profile tabs: Overview, Family & Households, Entities & Ownership, Advisors & Stakeholders. Header includes status, primary assignments and an as-of selector. Profile drawer exposes shared core and current group information. Forms have labels, required fields and server validation. Graphs include dates, relationship labels, historical percentages, zoom/pan, branches and record selection. Associates see read-only context; API rejects writes regardless of UI controls. Financial/workflow tabs are deferred, with scope explained in the interface.
